One wedding vow for a robot — a single sentence, under 200 characters, funny and heartfelt at the same time: "I vow that after a million simulations of forever, I choose the version where my battery dies beside yours." `main.py` (Python 3, standard library only) writes that line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
